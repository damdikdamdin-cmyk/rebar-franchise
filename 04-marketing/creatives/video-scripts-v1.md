## Технические требования

| Параметр | Значение |
|----------|----------|
| Соотношение | 9:16 (вертикальное) — приоритет |
| Разрешение | 1080×1920 |
| Длительность | 15–30 сек |
| Субтитры | Обязательно (80% смотрят без звука) |
| Формат | MP4, H.264 |
| Размер | до 30 MB (VK/Instagram) |
| Safe zone | 15% сверху и снизу (UI Stories) |

---

## Монтаж — рекомендации

- Переходы: быстрые cut, без длинных fade (темп Reels)
- Текст: Instrument Serif для заголовков, Manrope для body — или системный sans если нет шрифтов
- Цвет текста: белый на тёмном, chrome-акцент на ключевых цифрах
- Музыка: royalty-free, спокойный beat (не агрессивный EDM)
- Не использовать трендовые звуки с авторскими правами без лицензии

---

## Порядок съёмки (если снимаете на точках)

1. **Улан-Удэ:** вход, витрина, касса, момент продажи (с согласия), вывеска
2. **Иркутск:** то же — для монтажа «2 точки»
3. **Founder:** 2–3 дубля прямого обращения в камеру (15 сек каждый)
4. **B-roll:** упаковка, распаковка Re:Set, экран Lendo (без персональных данных)
