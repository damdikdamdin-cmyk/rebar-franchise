# ТЗ на баннеры v1

**Версия:** 1.0 · сентябрь 2026  
**Количество:** 5 баннеров (3 угла A/B/C + 2 универсальных)  
**Стиль:** steel/industrial — как лендинг v18

---

## Визуальный стиль

| Параметр | Значение |
|----------|----------|
| Фон | `#0a0b0d` (ink) с steel/chrome градиентом |
| Акцент | `#cfd2d6` (bg), chrome-градиент на кнопках |
| Заголовки | Instrument Serif (italic для акцентов) |
| Body | Manrope |
| Данные / eyebrow | JetBrains Mono |
| Фото | Реальные точки Улан-Удэ / Иркутск, не сток |
| Логотип | `re:bar` + точка (как на лендинге) |
| Настроение | Премиальный industrial, не «AI-шаблон», не яркий e-commerce |

### Запрещено
- Яркие неоновые цвета, градиенты «фиолетовый-розовый»
- Стоковые фото «улыбающийся продавец»
- Логотип Apple (юридический риск) — только «Apple и Samsung» текстом
- Мелкий шрифт с оговорками «*при определённых условиях»

---

## Размеры под площадки

| Площадка | Размеры (px) | Формат |
|----------|--------------|--------|
| Яндекс РСЯ | 240×400, 300×250, 300×600, 728×90, 970×250 | JPG/PNG, до 150 KB |
| VK | 1080×1080, 1080×1920 (Stories), 1200×628 | JPG/PNG |
| Instagram | 1080×1080 (feed), 1080×1920 (Stories/Reels cover) | JPG/PNG |
| Telegram | 1280×720 (превью поста) | JPG/PNG |

**Приоритет для дизайнера:** 1080×1080 (универсальный) + 1080×1920 (Stories) + 240×400 (РСЯ).

## Баннер 01 · Угол A — «Деньги»

**Файл:** `banner-01-money.png`

### Композиция
- Фон: тёмный steel, лёгкий metal-shine (как hero лендинга)
- Слева/сверху: eyebrow `ФРАНШИЗА RE:BAR`
- Заголовок (крупно): **0% роялти**
- Подзаголовок: Два потока дохода · окупаемость от 4 мес
- 3 маркера внизу (как hero-marks на лендинге):
  - `0%` роялти
  - `от 4 мес` окупаемость
  - `до 4%` доход на кредитах
- CTA-кнопка: «Получить презентацию»
- Логотип re:bar — правый нижний угол

### Текст на баннере (точный)
```
ФРАНШИЗА RE:BAR
0% роялти
Два потока дохода · окупаемость от 4 мес
[Получить презентацию]
```

## Баннер 02 · Угол B — «Доказательство»

**Файл:** `banner-02-proof.png`

### Композиция
- Фон: фото интерьера точки (Улан-Удэ или Иркутск) с тёмным overlay 60%
- Заголовок: **2 точки · 5 лет**
- Подзаголовок: Улан-Удэ — 950K чистыми/мес
- Мелкий текст: Иркутск — 550K · @applebar.ru 21K
- CTA: «Записаться на Zoom»
- Без перегруза цифрами — максимум 3 числа на баннере

```
2 ТОЧКИ · 5 ЛЕТ
Улан-Удэ — 950K чистыми/мес
Реальные магазины, не слайды
[Записаться на Zoom]
```

## Баннер 03 · Угол C — «Промо»

**Файл:** `banner-03-promo.png`

### Композиция
- Фон: тёмный с акцентной полосой chrome (как promo-panel на лендинге)
- Badge сверху: `АКЦИЯ ЗАПУСКА · 3 МЕСТА`
- Заголовок: **Паушал 100 000 ₽**
- Подзаголовок: вместо 250K–950K · любой формат
- Счётчик: `Осталось: 3`
- CTA: «Забронировать место»
- Срочность — но без кричащего красного; steel/chrome акценты

### Текст на баннере
```
АКЦИЯ ЗАПУСКА
Паушал 100 000 ₽
Любой формат · осталось 3 места
[Забронировать место]
```

## Чеклист для дизайнера

- [ ] Все 5 баннеров в 1080×1080
- [ ] Адаптация 01–03 в 1080×1920 (Stories)
- [ ] Адаптация 01 в 240×400 (РСЯ)
- [ ] Логотип re:bar на каждом
- [ ] Текст читается на мобильном (мин. 24px body, 48px+ заголовок)
- [ ] Safe zone 10% от краёв (для Stories — 15% сверху/снизу)
- [ ] Экспорт: PNG, sRGB, без сжатия артефактов
- [ ] Именование: `banner-{01-05}-{angle}-{size}.png`
