## Общие правила

- Не обещать «гарантированный доход» — только «по модели», «в наших точках», «окупаемость от 4 мес»
- Не писать «франшиза Apple» в заголовке без оговорки — риск претензий; в ключах Директа можно, в тексте — «техника Apple и Samsung»
- Всегда указывать **0% роялти** или **два потока дохода** — это главные дифференциаторы
- Длина заголовка Директ: до 56 символов; доп. заголовок: до 30; текст: до 81

# ТЗ на баннеры v1

**Версия:** 1.0 · сентябрь 2026

---

## Визуальный стиль

| Параметр | Значение |
|----------|----------|
| Фон | `#0a0b0d` (ink) с steel/chrome градиентом |
| Акцент | `#cfd2d6` (bg), chrome-градиент на кнопках |
| Заголовки | Instrument Serif (italic для акцентов) |
| Body | Manrope |
| Данные / eyebrow | JetBrains Mono |
| Фото | Реальные точки Улан-Удэ / Иркутск, не сток |
| Логотип | `re:bar` + точка (как на лендинге) |
| Настроение | Премиальный industrial, не «AI-шаблон», не яркий e-commerce |

### Запрещено
- Яркие неоновые цвета, градиенты «фиолетовый-розовый»
- Стоковые фото «улыбающийся продавец»
- Логотип Apple (юридический риск) — только «Apple и Samsung» текстом
- Мелкий шрифт с оговорками «*при определённых условиях»

---

## Технические требования

| Параметр | Значение |
|----------|----------|
| Соотношение | 9:16 (вертикальное) — приоритет |
| Разрешение | 1080×1920 |
| Длительность | 15–30 сек |
| Субтитры | Обязательно (80% смотрят без звука) |
| Формат | MP4, H.264 |
| Размер | до 30 MB (VK/Instagram) |
| Safe zone | 15% сверху и снизу (UI Stories) |

---

## Монтаж — рекомендации

- Переходы: быстрые cut, без длинных fade (темп Reels)
- Текст: Instrument Serif для заголовков, Manrope для body — или системный sans если нет шрифтов
- Цвет текста: белый на тёмном, chrome-акцент на ключевых цифрах
- Музыка: royalty-free, спокойный beat (не агрессивный EDM)
- Не использовать трендовые звуки с авторскими правами без лицензии

---

## Порядок съёмки (если снимаете на точках)

1. **Улан-Удэ:** вход, витрина, касса, момент продажи (с согласия), вывеска
2. **Иркутск:** то же — для монтажа «2 точки»
3. **Founder:** 2–3 дубля прямого обращения в камеру (15 сек каждый)
4. **B-roll:** упаковка, распаковка Re:Set, экран Lendo (без персональных данных)
