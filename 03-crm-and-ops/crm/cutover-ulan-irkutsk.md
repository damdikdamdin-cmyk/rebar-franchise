# Cutover LiveSklad → re:bar Hub (Улан-Удэ + Иркутск)

Цель: **день X — только Hub**. Параллельный режим продукта не нужен: до cutover тренировка на Hub, после — LiveSklad выключается.

## Подготовка (T−14…T−3)

- [ ] У всех продавцов УУ/Иркутск есть логины Hub (роли `seller` / привязка к точке)
- [ ] Обучение: POS-чек (S/N, скидка), поступление, возврат, инвентаризация, касса, отчёт
- [ ] Экспорт из LiveSklad (CSV): товары, остатки, клиенты по каждой точке
- [ ] Импорт в Hub: `/settings/import` (УК)
- [ ] Сверка остатков: топ-20 SKU + все серийники телефонов
- [ ] Кассы созданы, стартовый остаток денег внесён транзакцией
- [ ] Печать: пробный товарный чек + гарантийный талон (`/stores/[id]/print/sale/...`)

## День X (по точке)

1. [ ] Закрыть смену в LiveSklad, зафиксировать остатки и кассу на бумаге/скрине
2. [ ] Финальный импорт дельты остатков/клиентов (если нужно)
3. [ ] Инвентаризация критичных позиций в Hub
4. [ ] Первая продажа дня — только в Hub
5. [ ] LiveSklad: отозвать доступы сотрудников (read-only архив ОК)
6. [ ] Сообщить в чат точки: «работаем в Hub»

## После cutover (T+1…T+7)

- [ ] Ежедневная сверка кассы Hub vs факт
- [ ] Нет продаж/приходов в LiveSklad
- [ ] Собрать баги POS/склада в один список для УК
- [ ] Архив LiveSklad: выгрузка истории продаж (на всякий случай)

## Критерий готовности точки

За один рабочий день в Hub без LiveSklad: оприходовать поставку → продать телефон с S/N и скидкой → принять возврат → инвентаризация → касса и отчёт продаж.
