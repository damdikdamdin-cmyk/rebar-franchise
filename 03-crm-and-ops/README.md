## Решение по CRM

Своя платформа **re:bar Hub** (`05-hub/`), не AmoCRM и не Битрикс24. Одна база: воронка УК, кабинет запуска партнёра, розница точек и сводка сети.

## Задачи (приоритет)

1. Поднять Hub локально (`05-hub/README.md`) и завести команду по инвайтам
2. Подключить Telegram-уведомления (`TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID`)
3. Скрипты: первый звонок, Zoom, возражения, дожим
4. FAQ — 20 вопросов
5. Методичка запуска v1 (детализация по неделям + RACI)
