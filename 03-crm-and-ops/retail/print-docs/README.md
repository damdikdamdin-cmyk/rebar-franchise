# Печатные бланки точки (из re:bar / LiveSklad)

Исходники бланков, которыми пользуются продавцы и старшие смены. В Hub они доступны как редактируемые печатные формы: **Настройки → Печатные формы**.

| Бланк | Файл | Форма в Hub |
|-------|------|-------------|
| Акт приёма устройства | `Акт Приема.docx` | `act_accept` |
| Акт диагностики | `Акт диагностики.docx` | `act_diag` |
| Договор купли-продажи (выкуп б/у) | `Договор_купли_продажи_товара.docx` | `contract_buy_used` |
| Заявление на возврат ДС | `Заявление на возврат ден средств.doc` | `refund_claim` |
| Расходный кассовый ордер | `Расходный кассовый ордер.docx` | `cash_out_order` |
| Согласие на диагностику и ремонт | `Согласие на диагностику и ремонт.doc` | `consent_diag_repair` |
| Согласие на диагностику | `Согласие на диагностику.doc` | `consent_diag` |
| Согласие на ремонт | `Согласие на ремонт.doc` | `consent_repair` |
| Бланк с шапкой | `Шаблон документа с шапкой для ИП Цыпылов.docx` | `letterhead` |
| Договор на гарантийное обслуживание | `договор о гарантийном обслуживании.doc` | `contract_warranty_service` |

Дополнительно в Hub (без исходников Word): гарантийный талон, товарный чек, большой/маленький ценник, этикетка 43×25, этикетка IMEI, приходная накладная.

При печати подставляются переменные из продажи / товара / клиента: цена, гарантия, IMEI, штрихкод, реквизиты точки.
