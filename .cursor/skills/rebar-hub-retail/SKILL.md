# re:bar Hub · Розница (LiveSklad → Hub)

## Источник правды

Действующая CRM точек — **LiveSklad** (скриншоты в чате / `assets/`).
Hub копирует **механики**, не UI-бренд LiveSklad. Визуал Hub — industrial re:bar
(ink/paper/steel, Instrument Serif / Manrope / JetBrains Mono).

Не путать с воронкой франшизы УК: розница живёт на уровне **Store**.

Мобильный чек LiveSklad (цена / скидка ₽|% / кол-во / клиент) → `/pos` mobile layout.

## Инварианты склада

1. Остаток меняется **только** через документы: поступление, продажа, возврат, перемещение, инвентаризация, списание.
2. Серийный товар (IMEI/S/N) обязателен для телефонов и аналогов (`serialTracked = true`).
3. Цены: закуп / розница / ремонтная / под заказ.
4. Документ имеет номер, дату, склад, сотрудника, сумму, комментарий.
5. Мультиточечность: «другие локации» в POS показывают qty на сестринских Store сети (UK видит все; партнёр — свои).
6. После продажи: уменьшаем остаток + пишем Sale + (P1) транзакцию в кассу.

## Модель данных (минимум P0)

См. `references/schema-p0.md` при расширении схемы.

- `Product` — код, штрихкод, группа, серийность, гарантия, цены, мин. остаток
- `ProductGroup` — дерево групп (Apple / Samsung / Аксессуары)
- `StockBalance` — qty по `storeId` + `productId` (+ optional serial)
- `StockDocument` + `StockLine` — поступления / перемещения / списания / инвентаризации
- `Sale` / `SaleLine` — чек с позициями, скидками, клиентом, Lendo
- `Supplier` — поставщик на поступлениях
- `CashRegister` + `CashTxn` — касса точки (P1)

## UX-паттерн (из LiveSklad)

- Левый сайдбар модулей точки (не только франшиза-навигация УК)
- Таблица + поиск + период + склад-фильтр + «+ Создать»
- POS: каталог слева, чек справа (или мобильный single-column)
- Футер таблицы: «Всего документов — N на сумму X»
- Не копировать синий UI LiveSklad — токены Hub

## Порядок внедрения

1. Справочник товаров + группы + остатки
2. POS-чек (позиции, скидка, клиент) → движение склада
3. Поступления от поставщика
4. Касса / транзакции / денежный поток
5. Перемещения между точками + возвраты + инвентаризация
6. Отчёты и печатные формы (гарантийный талон)
