## re:bar OS — правила работы

- Роли и права — `06-crm/src/lib/access.ts`; навигация — `src/lib/nav.ts`. Новый раздел = пункт в `navFor` + проверка доступа на странице.
- База знаний наполняется из репо: добавить документ → строка в `scripts/kb-manifest.ts` → `npm run kb:import`. Правки импортированных статей делать в исходных файлах, не в UI.
- Курсы и чек-листы «изучил» — `COURSES` в том же манифесте.
- Партнёр появляется только через «Подключить партнёра» в карточке лида (или `/partners?new=1` для админа) — создаётся точка, проект запуска и инвайт.
- `03-crm-and-ops/legal/06_*.docx`, `07_*.docx` повреждены; актуальные тексты — `*_FINAL_v3.1.md` рядом.
